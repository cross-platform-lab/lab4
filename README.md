# Lab 4: Magic 8 Ball

Quả cầu tiên tri trả lời ngẫu nhiên các câu hỏi Có/Không.

## Chức năng

- Nhấn vào quả cầu hoặc nút **Hỏi quả cầu** để nhận câu trả lời ngẫu nhiên (`Random`).
- Đổi hình `assets/images/ball1..5.png` và văn bản câu trả lời tương ứng.

## Cấu trúc chính

- `lib/main.dart`
- `assets/images/`

## Chạy ứng dụng

```bash
flutter pub get
flutter run
```
